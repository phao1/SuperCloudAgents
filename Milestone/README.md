## 使用架构工作台

- **工作视图与全景**。打开时以 135% 比例浏览局部，点击「全景」可将原图完整放入画布。用鼠标拖动空白区域平移，滚轮或底部的「−」「+」按钮可缩放，「1:1」恢复原始尺寸。触屏可以单指平移、双指缩放。
- **查找模块**。用「定位分区」跳到原图的对应区域，或按模块名、技术栈和路径搜索。打开「模块目录」可按分区查找全部 64 项能力，包括原图之外的 14 项 V2 补充能力。
- **查看实现**。点击图上的节点，或从搜索结果、目录选择模块，即可在侧边详情查看当前实现、范围边界和对应的代码、测试与设计记录。手机上详情从画布底部打开。打开「显示实现进度」可查看原图的状态着色，底栏可按状态筛选。
- **阅读阶段和依据**。顶部导航可切换「阶段里程碑」「下一步演进」和「依据说明」，点击「架构图」返回画布。

键盘操作时，按 `/` 聚焦搜索，按 Enter 打开首条搜索结果或已聚焦的图中节点。焦点在画布时，方向键平移，`+` 和 `-` 缩放，`0` 切到全景。Esc 关闭当前打开的搜索结果、模块目录或详情。

## 文件与运行契约

- `data.json` 保存模块与元信息；`app.js` 保存阶段和路线图文字及交互；`template.html`、`styles.css` 是页面源。
- `build.py` 仅使用标准库生成内嵌 SVG、数据、CSS 和 JS 的 `index.html`；无需后端或本地服务器。
- `validate.py` 固定日期/提交、50 原图节点、14 个 V2 ID 和 64 总数，校验字段、状态、源 SVG SHA-256、生成页数据与节点覆盖，并对全部 **210 个唯一证据路径**执行 `git cat-file -e <baseline>:<path>`。校验需要本地 Git 及目标提交对象，无需网络。
- 本次没有修改平台 endpoint、设置、迁移或源 SVG。各能力的现有 endpoint、设置和文件布局写在模块详情，并链接到目标提交的实现。
