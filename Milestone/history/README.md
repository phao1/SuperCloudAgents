## Windows 查看历史

在 PowerShell 进入仓库根目录，用本机 Python 3 启动历史回放。

```powershell
py -3 scripts/serve_portal_history.py
```

浏览器打开 <http://127.0.0.1:8000/portal>。从旧版更新后，在原 PowerShell 窗口按 Ctrl+C 并重新运行脚本。端口被其他程序使用时，可加 `--port 8001`。用同一端口访问 `/healthz` 可以看到 `"portal":"archive"` 和 `"task_progress":true`。

| 页面 | 可查看的记录 |
| --- | --- |
| 任务进度 `#/tasks` | 从最近任务选择任一归档任务，回放架构图，查看执行泳道、验证与原始事件。 |
| 共享记忆 `#/memories` | 1 条已公开的订单仓库约定，可用范围筛选，点开 [T010 的第 61 个事件](../portal-run-2026-11-19.md#L108)查看记忆命中。 |
| 任务历史 `#/history` | 筛选和展开 64 条任务的 2,869 条执行事件。 |
| 概览、评测中心与数据分析 | 任务汇总、3 条公开评测运行与已归档的分析任务。 |
| 项目、版本对比、版本谱系、自演进闭环与自动演进 | 已公开的项目案例、版本、基线与回归记录。 |
| 工具与知识库、集成、团队与用量、平台管理 | 已归档的工具与 CI 事件、后端任务量和部署说明。 |

团队成员、配额、私有知识库及其余共享记忆需要在有权限的在线工作空间查看。
